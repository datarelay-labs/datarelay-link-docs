# Quick Start

<Note>
  Complete [Server installation](/getting-started/server-installation) first. Run each command on the Server or Agent Host identified below.
</Note>

## 1. Verify the Server

```bash
sudo drlink
```

Then run:

```text
system version
show status
system diagnostics
```

The role must be **DRLink Server**.

## 2. Issue a Zero-Touch enrollment

On the Server:

```text
set enrollment zero-touch
```

Select **Linux**, enter the Managed Host name/description, choose **SSH only** and the actual SSH port (default 22). Run the generated one-time command on the target host.

Services selected through Zero-Touch **SSH only**, **RDP only** or **Choose Remote Services** automatically receive the required Service Object, Remote Service and public endpoint reservation during enrollment. Do not create the same service manually again. Inspect actual names with `show remote-services` on the Agent.

**A blank username in SSH only affects connection hints; it is not management-only enrollment.** To enroll without publishing services, run `set enrollment bulk`, choose count **1** and leave the SSH username blank. Choose Remote Services requires at least one service. OS accounts, sshd/RDP, external firewalls and Access Policy rules remain separate.

## 3. Verify the Agent Host

On the newly enrolled host:

```bash
sudo drlink
```

Then:

```text
show status
show agent
```

The role must be **Agent Host**.

## 4. Inspect the automatically created service

```text
show remote-services
show remote-service <actual-service-name>
```

The endpoint is allocated and managed by DataRelay Link. Temporary Server or target failure can leave a valid Remote Service in DEGRADED state.

## 5. Optional: restrict Remote Access

With no policy configured, effective access is ALLOW.

On the Server:

```text
set network-object office-admin type ip value 203.0.113.10
set remote-access office-ssh mode whitelist source office-admin destination <managed-host> service ssh enabled
set remote-access enabled
test remote-access source office-admin destination <managed-host> service ssh
```

## 6. Connect

Use the endpoint shown by the Agent:

```bash
ssh -p <public-port> <username>@<public-hostname>
```

DataRelay Link does not create OS users or configure sshd; the target account/service must already exist.

Replace `<actual-service-name>` and the policy service selector `ssh` with the actual Remote Service and Service Object names. Review source restrictions before publishing and inspect existing Object definitions before editing.
