# macOS Agent Host

The macOS Agent uses an Apple Silicon Agent Host. Use the Zero-Touch command generated by the Server rather than copying a stale fixed installer command from older documentation.

## Enroll

On the Server:

```text
set enrollment zero-touch
```

In the wizard select **macOS → SSH only** or **Choose Remote Services**, enter the host name/description and actual target ports. Services selected through Zero-Touch **SSH only**, **RDP only** or **Choose Remote Services** automatically receive the required Service Object, Remote Service and public endpoint reservation during enrollment. Do not create the same service manually again. Inspect actual names with `show remote-services` on the Agent.

Run the generated command on the target Mac with the required administrator privileges.

## Verify

```bash
sudo drlink
```

```text
show status
show agent
system info
system diagnostics
```

## Lifecycle

```text
system pause
system resume
system restart
system synchronize
system autostart enable
system autostart disable
system update product
system update engine
system uninstall
```

DataRelay Link does not enable Remote Login, create macOS users, or change application credentials.
