# macOS Agent Host

The qualified macOS path uses an Apple Silicon Agent Host. Use the Zero-Touch command generated by the Server rather than copying a stale fixed installer command from older documentation.

## Enroll

On the Server:

```text
set enrollment zero-touch
```

Run the generated command on the target Mac with the required administrator privileges.

## Verify

```bash
sudo drlink
```

```text
show status
show agent
system info
system diagnostics
```

## Lifecycle

```text
system pause
system resume
system restart
system update product
system update engine
system uninstall
```

DataRelay Link does not enable Remote Login, create macOS users, or change application credentials.
