# What is DataRelay Link?

DataRelay Link is a lightweight secure-connectivity gateway for environments where you need selected connectivity without opening or joining an entire network.

## Three access planes

| Plane | Direction | Purpose |
| --- | --- | --- |
| Remote Access | outside → inside | Authorize use of Agent-owned Remote Services |
| Internet Access | inside → outside | Permit approved outbound destinations |
| AI Access | AI → managed target | Authorize verified AI Identities to explicit permissions |

## Connectivity and authorization are separate

```text
Remote Service
→ actual connectivity and stable endpoint

Access Policy
→ authorization only
```

Creating a Rule does not create a tunnel or endpoint.

## Two CLI contexts

**DRLink Server** owns Managed Hosts, enrollment, Network/Service/Permission Objects and Groups, AI Identities, Access Policies, audit, backup/restore, and Server ConfigurationBundle.

**Agent Host** owns local Agent lifecycle, Remote Services, local diagnostics, and Agent ConfigurationBundle.

Remote Service mutation belongs on the Agent Host that owns it.
