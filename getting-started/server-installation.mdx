# Server installation

<Note>New installation? Follow [Choose your first workflow](/getting-started/choose-workflow) for the correct order of Server installation, enrollment, MCP, ACL and real ALLOW/DENY checks.</Note>

## Prerequisites

- A supported Linux Server and administrator access.
- A public address or DNS name reachable by Agents.
- The paths described in [firewall/NAT requirements](/deployment/firewall-nat).
- For remote MCP, public DNS and HTTPS plus single443 deployment.

## 1. Run the Server installer

Use an **operator-approved immutable commit** or qualified release artifact, never a mutable `main` or unqualified `latest` installer. Replace the SHA placeholder with the approved 40-character commit. Do not execute the example unchanged:

~~~bash
# Obtain the operator-approved immutable 40-character Git commit SHA.
SOURCE_SHA="REPLACE_WITH_APPROVED_40_CHARACTER_COMMIT_SHA"
printf '%s' "$SOURCE_SHA" | grep -Eq '^[0-9a-f]{40}$' || { echo "Invalid SHA"; exit 1; }
curl -fsSL "https://raw.githubusercontent.com/datarelay-labs/datarelay-link/$SOURCE_SHA/dist/bootstrap-server.sh" -o bootstrap-server.sh
sha256sum bootstrap-server.sh  # Compare with an independently approved artifact digest, if supplied.
sudo bash ./bootstrap-server.sh
~~~

Follow the prompts for the external address and deployment mode. Select **single443** for Claude/ChatGPT remote MCP, then configure public HTTPS and OAuth in the [MCP connection guide](/guides/mcp-clients).

## 2. Verify installation

~~~bash
sudo drlink system version
sudo drlink show status
sudo drlink system diagnostics
~~~

Confirm role **DRLink Server**, the installed **source/version identity**, and healthy services. Installer exit alone does not prove that a release is stable. Resolve diagnostic errors using [troubleshooting](/troubleshooting/overview).

## 3. Configure the connection you need

| Goal | Next steps |
| --- | --- |
| Reach internal services | [Enroll an Agent](/guides/enrollment) → [SSH tutorial](/use-cases/remote-ssh) |
| Approve restricted Internet traffic | [Internet Access](/guides/internet-access) |
| Operate from Claude/ChatGPT | [MCP connection](/guides/mcp-clients) → [AI Access](/guides/ai-access) |

The Server owns enrollment, inventory, policy, AI Identity, audit and backups. Create Remote Services on the owning Agent Host. Prepare external firewall/DNS, SSH accounts and application certificates in your environment.
