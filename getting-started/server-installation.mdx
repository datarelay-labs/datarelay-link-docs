# Server installation

## Prerequisites

- A supported Linux Server and administrator access.
- A public address or DNS name reachable by Agents.
- The paths described in [firewall/NAT requirements](/deployment/firewall-nat).
- For remote MCP, public DNS and HTTPS plus single443 deployment.

## 1. Run the Server installer

Download and run the official Server installer:

~~~bash
curl -fsSL https://raw.githubusercontent.com/datarelay-labs/datarelay-link/main/dist/bootstrap-server.sh -o bootstrap-server.sh
sudo bash ./bootstrap-server.sh
~~~

Follow the prompts for the external address and deployment mode. Select **single443** for Claude/ChatGPT remote MCP, then configure public HTTPS and OAuth in the [MCP connection guide](/guides/mcp-clients).

## 2. Verify installation

~~~bash
sudo drlink system version
sudo drlink show status
sudo drlink system diagnostics
~~~

Confirm role **DRLink Server** and healthy services. Resolve diagnostic errors using [troubleshooting](/troubleshooting/overview).

## 3. Configure the connection you need

| Goal | Next steps |
| --- | --- |
| Reach internal services | [Enroll an Agent](/guides/enrollment) → [SSH tutorial](/use-cases/remote-ssh) |
| Approve restricted Internet traffic | [Internet Access](/guides/internet-access) |
| Operate from Claude/ChatGPT | [MCP connection](/guides/mcp-clients) → [AI Access](/guides/ai-access) |

The Server owns enrollment, inventory, policy, AI Identity, audit and backups. Create Remote Services on the owning Agent Host. Prepare external firewall/DNS, SSH accounts and application certificates in your environment.
