# Windows Agent Host

Windows is an Agent Host platform; the DRLink Server remains Linux-based.

Use the enrollment command generated by the Server. Do not use obsolete v2.2 client commands or copy old fixed bootstrap URLs.

## Enroll

On the Server:

```text
set enrollment zero-touch
```

In the wizard select **Windows → RDP only** or **Choose Remote Services**, enter the host name/description and actual target ports. Services selected through Zero-Touch **SSH only**, **RDP only** or **Choose Remote Services** automatically receive the required Service Object, Remote Service and public endpoint reservation during enrollment. Do not create the same service manually again. Inspect actual names with `show remote-services` on the Agent.

Run the generated Windows installation/enrollment command according to the product installation instructions.

## Verify

Open the DataRelay Link CLI on the Windows Agent Host and verify:

```text
show status
show agent
system info
system diagnostics
```

## Remote Services

Create only additional Remote Services on the Windows Agent Host after inspecting the enrollment-created services. RDP is represented as TCP/3389 through a Service Object; DataRelay Link does not enable RDP, create Windows credentials, or weaken Windows Firewall/NLA settings.

## Lifecycle

Use Agent lifecycle operations such as pause, resume, restart, product update, engine update, diagnostics, support bundle, and uninstall as exposed by the Windows CLI/package.
