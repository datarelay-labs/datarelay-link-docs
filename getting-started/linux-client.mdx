# Linux Agent Host

A Linux target becomes a **Managed Host** after enrollment and runs the **DRLink Agent**.

## Enroll

On the DRLink Server:

```text
set enrollment zero-touch
```

In the wizard select **Linux → SSH only** or **Choose Remote Services**, enter the host name/description and actual target ports. Services selected through Zero-Touch **SSH only**, **RDP only** or **Choose Remote Services** automatically receive the required Service Object, Remote Service and public endpoint reservation during enrollment. Do not create the same service manually again. Inspect actual names with `show remote-services` on the Agent.

Run the generated one-time command on the target Linux host.

## Verify on the Agent Host

```bash
sudo drlink
```

```text
show status
show agent
system info
system diagnostics
```

## Inspect enrolled connectivity

Remote Services are created on the owning Agent Host:

```text
show remote-services
show remote-service <actual-service-name>
```

For another reachable LAN host, use that destination rather than this-host. The current Agent Host becomes the Relay Host.

## Agent lifecycle

```text
system pause
system resume
system restart
system synchronize
system autostart enable
system autostart disable
system update product
system update engine
system diagnostics
system support-bundle
```

Pause/Resume/Restart/Agent update are Agent-only lifecycle operations.
