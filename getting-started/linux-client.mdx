# Linux Agent Host

A Linux target becomes a **Managed Host** after enrollment and runs the **DRLink Agent**.

## Enroll

On the DRLink Server:

```text
set enrollment zero-touch
```

Run the generated one-time command on the target Linux host.

## Verify on the Agent Host

```bash
sudo drlink
```

```text
show status
show agent
system info
system diagnostics
```

## Create connectivity

Remote Services are created on the owning Agent Host:

```text
set remote-service ssh-access destination this-host service ssh enabled
show remote-service ssh-access
```

For another reachable LAN host, use that destination rather than this-host. The current Agent Host becomes the Relay Host.

## Agent lifecycle

```text
system pause
system resume
system restart
system update product
system update engine
system diagnostics
system support-bundle
```

Pause/Resume/Restart/Agent update are Agent-only lifecycle operations.
