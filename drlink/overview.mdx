# drlink Guide

The primary operator interface is:

```bash
sudo drlink
```

## DRLink Server owns

```text
Managed Hosts / Enrollments
Network Objects / Groups
Service Objects / Groups
Permission Objects / Groups
AI Identities
Remote Access
Internet Access
AI Access
Server ConfigurationBundle
revision / audit / backup / restore / system operations
```

## Agent Host owns

```text
Status
Remote Services
Agent lifecycle
Agent ConfigurationBundle
local diagnostics
```

Remote Service mutation belongs to the owning Agent Host.

## Common roots

```text
show
set
unset
test
system
menu
help
exit
```

Use ?, help, contextual help, and Tab completion for discovery. Wrong-context operations should explain which role owns the requested operation.
