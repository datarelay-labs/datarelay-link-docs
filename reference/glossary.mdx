# Glossary

| Term | Meaning |
| --- | --- |
| DRLink Server | Central control/policy authority and public relay entry point |
| Managed Host | A host enrolled and managed through a DRLink Agent |
| DRLink Agent | Runtime installed on a Managed Host |
| Network Object | Reusable IP, CIDR, FQDN, or Managed Host selector |
| Network Group | Flat group of Network Objects |
| Service Object | Reusable TCP, UDP, or Fixed TCP service definition |
| Service Group | Flat group of Service Objects |
| Permission Object | Reusable AI-operation permission set |
| Permission Group | Flat group of Permission Objects |
| AI Identity | Authenticated identity used for AI Access |
| Remote Service | Agent-owned connectivity object binding destination and Service Object |
| Relay Host | Agent Host relaying to another reachable LAN destination |
| Remote Access | Authorization for inbound use of Remote Services |
| Internet Access | Authorization for controlled outbound destinations |
| AI Access | Authorization from verified AI Identity to target permissions |
| BLACKLIST | Matching enabled Rule denies; no match allows |
| WHITELIST | Matching enabled Rule allows; no match denies |
| ConfigurationBundle | Multi-resource validate/diff/apply configuration document |
| DEGRADED | Configured object exists but runtime health/synchronization is incomplete |
