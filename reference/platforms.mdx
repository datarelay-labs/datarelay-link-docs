# Supported Platforms

## Role boundary

| Role | Platform boundary |
| --- | --- |
| DRLink Server | Linux-based |
| Agent Host | Linux plus qualified macOS and Windows paths |

The exact platform matrix is release-evidence dependent. Do not infer stable support for a platform solely because code exists.

## Current documentation target

This site describes the **v2.4.0 development target**. The latest published stable release is **v2.3.0**.

Agent platform pages describe the current product model, while exact Real E2E qualification for v2.4 remains tied to candidate evidence.

## Product scale

The intended scale remains roughly a few systems to a few dozen Managed Hosts. DataRelay Link is not a large-fleet endpoint orchestrator.

## Network boundary

Agent Hosts normally connect outbound to the Server. DataRelay Link does not require every Managed Host to have a public IP or inbound NAT rule.
