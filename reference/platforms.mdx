# Supported Platforms

## Role boundary

| Role | Platform boundary |
| --- | --- |
| DRLink Server | Linux-based |
| Agent Host | Linux, macOS Apple Silicon and Windows |

Use the platform-specific installation guide for administrator privileges and autostart requirements.

## Product scale

The intended scale remains roughly a few systems to a few dozen Managed Hosts. DataRelay Link is not a large-fleet endpoint orchestrator.

## Network boundary

Agent Hosts normally connect outbound to the Server. DataRelay Link does not require every Managed Host to have a public IP or inbound NAT rule.
