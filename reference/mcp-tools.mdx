# The 20 Native MCP tools

The table lists DataRelay Link MCP tool names, required arguments and permissions. Client namespace prefixes may vary. These are AI tool calls, separate from drlink CLI commands.

| Tool | Required arguments | DRLink permission | Purpose |
| --- | --- | --- | --- |
| **get_server** | None | host-info | Discover the authorized Server itself |
| **list_hosts** | None | host-info | List accessible Managed Hosts |
| **get_host** | endpoint | host-info | Inspect a Managed Host |
| **get_system_info** | endpoint | host-info | Read system identity |
| **list_processes** | endpoint | process-read | Read processes |
| **read_file** | endpoint, path | file-read | Read a scoped file |
| **write_file** | endpoint, path, content | file-write | Write a scoped file |
| **delete_file** | endpoint, path | file-write | Delete a regular file |
| **upload_file** | endpoint, path, content | file-upload | Upload file content |
| **download_file** | endpoint, path | file-download | Download file content |
| **exec** | endpoint, command | command-exec | Execute on the selected target |
| **server_read_file** | path | file-read | Read Server-local file |
| **server_write_file** | path, content | file-write | Write Server-local file |
| **server_delete_file** | path | file-write | Delete Server-local file |
| **server_run** | cwd, argv | command-exec | Run general argv in full-control mode |
| **server_exec** | cwd, command | command-exec | Execute a shell command |
| **server_git** | cwd, argv | command-exec | Run Git including local commit/push |
| **server_job_poll** | job_id | command-exec | Read job state and output |
| **server_job_input** | job_id | command-exec | Send stdin/EOF |
| **server_job_stop** | job_id | command-exec | Stop the caller-owned job |

## Targets and OS account

Use an endpoint returned by **list_hosts/get_host** for a Managed Host. **server_*** and get_server target the Server and do not take endpoint. Generic endpoint=server:self operations require explicit Server management permission.

Server-local shell, Git, service and package commands use the configured OS account and AI Access. **cwd is an initial-directory check, not a filesystem sandbox for a general shell.**

## Arguments and results

| Tools | Optional arguments / behavior |
| --- | --- |
| server_exec / server_run / server_git | timeout_seconds: 1–86400, default 3600; wait_ms: 0–5000, default 1000 |
| server_job_poll | stdout_cursor / stderr_cursor: byte offsets, default 0; wait_ms: 0–5000 |
| server_job_input | data: UTF-8 string, default empty; eof: boolean, default false |

argv is a string array; server_git begins with git. Paths/cwd are absolute. Inspect **job_id, state, exit_status, stdout, stderr, execution_user**. Running is not successful completion. Resume each stream using **next_cursor**, or use **data_b64** for exact bytes. Retention is at most 1 MiB per stream, 64 KiB per page; inspect cursor eviction. stdin accepts at most 64 KiB; inspect **accepted_bytes** before retrying unsent bytes. Completed jobs remain up to ten minutes or bounded-history reclamation, not a durable restart-safe queue.

Poll/input/stop recheck current command-exec, identity and job ownership. Another identity cannot control a job simply by knowing its ID. Direct file operations require their own permission, rule-bound paths and OS access.
