# Product version and updates

## Inspect the installed version

Run from the Server or Agent Host shell:

~~~bash
sudo drlink system version
~~~

The output identifies product version, channel, Relay Engine and host role. Include this information when diagnosing a Server or Agent problem.

## Product and Relay Engine

DataRelay Link and its included Relay Engine have separate versions. Product updates deliver management/security/compatibility changes; engine updates refresh the connection engine.

~~~text
system update product
system update engine
~~~

Check the host role and update impact first. Before a Server change, create a [backup](/operations/backup-restore), then verify status and real service connectivity afterward. Follow the [update procedure](/operations/updates).

## Manual scope

This site explains the installed product's Managed Hosts, Remote Services, Remote/Internet/AI Access and ConfigurationBundle. If a documented command is absent from an older installation, update the product and check again. Get distribution files and change notes from the [official releases page](https://github.com/datarelay-labs/datarelay-link/releases).

On the Server, use `system update check-engine` to inspect available engine updates without applying them.
