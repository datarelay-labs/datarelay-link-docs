# Release Status

## Published stable

The latest published GitHub release is **v2.3.0**.

Stable field deployment must use the immutable release/tag and its qualified artifacts rather than mutable development branches.

## Current development target

This documentation is being updated for **v2.4.0 development**.

v2.4 introduces the current Managed Host / Object / Remote Service / Remote Access / Internet Access / AI Access / ConfigurationBundle model documented on this site.

<Warning>
  A v2.4 source tree, VERSION value, branch name, or documentation page does not make v2.4 stable. Stable publication requires exact-HEAD qualification and an immutable release/tag.
</Warning>

## Relay Engine

DataRelay Link product version and Relay Engine version are separate. The currently pinned Relay Engine in the v2.4 development target remains FRP 0.71.0 unless release metadata changes.

## Source of truth

For stable deployment identity, use the latest published GitHub Release. For current v2.4 product behavior under development, use the Product Master, CLI/AI Master, and exact qualification evidence in the product repository.
