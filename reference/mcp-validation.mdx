# Claude and ChatGPT MCP compatibility

DataRelay Link connects to Claude and ChatGPT over remote MCP. Real OAuth connection, tool discovery, command execution and file create/read/delete have been verified with both clients.

## Connection and basic operations

| Capability | Claude | ChatGPT |
| --- | --- | --- |
| Remote HTTPS MCP | Verified | Verified |
| OAuth and operator consent | Verified | Verified |
| Tool discovery | Verified | Verified |
| Server information and commands | Verified | Verified |
| File create/read/delete | Verified | Verified |

Client account/workspace controls and DataRelay Link AI Access determine which actions are available. Authentication does not authorize ungranted targets, operations or file paths.

## Available workflows

- Read system/process information from enrolled Managed Hosts.
- Read/write/upload/download within approved file scopes.
- Run Server-local commands, Git and asynchronous jobs with output/input/stop.
- Inspect actual allowed/denied activity through AI Access audit.

See [all 20 tool permissions and arguments](/reference/mcp-tools). OS permissions and external service authentication still apply. GitHub operations also require repository Git authentication.

## Verify after connection

Ask either client:

~~~text
Use only DataRelay Link get_server to identify the connected Server.
Show the Managed Hosts I can access with list_hosts.
Do not execute commands or change files yet.
~~~

Server administration and Managed Host access are separate grants. An empty host list does not imply Server-self is unavailable. Continue with [read-only access](/use-cases/ai-readonly) or the [file/Git/job tutorial](/use-cases/ai-server-control).

## Troubleshooting

| Symptom | Check |
| --- | --- |
| TLS error | Public MCP hostname, certificate and external HTTPS reachability |
| Missing/expired OAuth request | Correct Server and current browser request |
| AI Access DENY | Actual identity, target, permission and paths |
| OS permission error | Product execution account and file/command permissions |
| Missing tools | Client's saved tool catalog and account policy |

Follow the [client connection guide](/guides/mcp-clients) for recovery.
