# DNS & Public Hostname

DataRelay Link distinguishes several names that older documentation mixed together.

| Name | Purpose |
| --- | --- |
| Product public identity | Server control/management identity selected during installation |
| Remote Service alias | Optional user-facing hostname for Remote Service endpoints |
| Bootstrap hostname | Optional hostname used for Zero-Touch bootstrap entry |

If installation selects a domain as the product public identity, generated Zero-Touch and other product-facing URLs must use that identity consistently.

Changing a friendly Remote Service alias must not silently change Agent identity, policy selectors, or the Server trust identity.

DataRelay Link does not create DNS-provider records. Create and validate required DNS records outside the product.
