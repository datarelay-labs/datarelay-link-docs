# Deployment Modes

DataRelay Link supports two Server deployment modes.

## Direct

Typical public listeners include:

```text
TCP/443        Relay control
TCP/6099       management/enrollment HTTPS
TCP/6000-6098 Remote Service endpoint pool
```

## Enterprise single-443

Management/enrollment HTTPS and Relay control share public TCP/443 through the DataRelay Link frontend, while internal backend listeners remain loopback-only.

Remote Service endpoints remain separately allocated from their configured endpoint pools.

## Important boundaries

Changing deployment mode is a controlled lifecycle operation. It must preserve the v2.4 authoritative control-plane database, Managed Host/Agent identities, Remote Services, endpoint reservations, policy state, and trust material.

The installer does not change cloud security groups, customer firewall/NAT rules, or DNS-provider records.

Use single-443 when restrictive enterprise networks permit standard HTTPS/WSS on 443 but interfere with TLS on non-standard ports.
