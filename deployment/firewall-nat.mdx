# Firewall & NAT

DataRelay Link does not automatically change cloud security groups, customer firewalls, NAT/DNAT, UFW/firewalld, or external routers.

## Direct mode

Typical inbound requirements are:

```text
TCP/443        Relay control
TCP/6099       management/enrollment HTTPS
TCP/6000-6098 Remote Service endpoint pool
```

Only expose endpoint pools actually configured by the deployment. Fixed TCP uses a separately configured endpoint pool when enabled.

## Enterprise single-443

Typical inbound requirements are:

```text
TCP/443        management/enrollment + Relay control
Remote Service endpoint pool(s)
```

Internal allocator/Relay Engine backend listeners must remain private/loopback-only.

## Agent Hosts

Managed Hosts normally initiate their control/management connections outbound to the Server. They do not require a public IP or inbound NAT solely to operate the Agent.
