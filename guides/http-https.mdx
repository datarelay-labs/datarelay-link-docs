# HTTP & HTTPS Remote Services

Create normal TCP Service Objects for the destination ports:

```text
set service-object http type tcp port 80
set service-object https type tcp port 443
```

On the Agent Host:

```text
set remote-service web-http destination this-host service http enabled
set remote-service web-https destination this-host service https enabled
```

## HTTPS behavior

Remote Service forwarding is TCP transport. DataRelay Link does not terminate or replace the target application's HTTPS certificate.

If a browser reaches an HTTPS target through a DataRelay Link endpoint, certificate-name validation still belongs to the application/TLS endpoint design.

Use Remote Access policy separately when the service should not be reachable by every source.
