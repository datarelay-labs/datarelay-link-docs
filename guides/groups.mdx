# Objects & Groups

DataRelay Link v2.4 uses explicit Object families.

## Network Objects

Normal user-created types are IP, CIDR, and FQDN. Registered Managed Hosts also appear as Network Objects of type Managed Host.

```text
set network-object github type fqdn value github.com
set network-group approved-admins members office-admin,vpn-admin
```

## Service Objects

Schema types are TCP, UDP, and Fixed TCP. The normal Wizard offers SSH, HTTP, HTTPS, RDP, Custom TCP, and Fixed TCP.

UDP can exist through explicit configuration, but Remote Service and Internet Access v2.4 reject UDP use.

```text
set service-object ssh type tcp port 22
set service-group web-services members http,https
```

## Permission Objects

Permission Objects contain reusable AI-operation permissions.

```text
set permission-object read-only permissions host-info,process-read,file-read
set permission-group operators members read-only,operator
```

## Group rules

Groups are flat reusable collections. Context validation applies to the whole selected Group. Internet Access destination, for example, rejects a Network Group if any member is a Managed Host.
