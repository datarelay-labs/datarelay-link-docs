# Managed Host Enrollment

Enrollment turns a real host into a **Managed Host** by installing and binding the DRLink Agent to the Server.

## Server commands

```text
set enrollment zero-touch
set enrollment manual
set enrollment bulk
show enrollments
show enrollment <ENROLLMENT>
```

After enrollment:

```text
show managed-hosts
show managed-host <HOST>
```

## Identity boundary

Managed Host identity is tied to the enrolled Agent/machine identity, not merely to a display label, hostname, or observed NAT/public IP.

Enrollment credentials are bootstrap credentials. They are not the same as the persistent Agent management identity or Relay Engine transport credential.
