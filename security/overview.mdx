# Security Overview

## Enrollment trust

Zero-Touch tickets are single-use, time-bounded credentials. Raw ticket material is not a normal redisplayable Server secret.

## Agent identity

Managed Host identity is based on enrolled Agent/machine identity, not merely hostname, display label, or observed source IP.

## Policy semantics

Remote Access, Internet Access, and AI Access use BLACKLIST or WHITELIST Mode plus ENABLED or DISABLED enforcement.

Rules are unordered and do not carry per-rule actions.

Disabling enforcement preserves Mode and Rules but makes policy effective ALLOW ALL. Reset removes Mode and Rules.

## Internet Access safety

Internet Access must not become an open proxy. Destination validation, protocol/port validation, safe DNS resolution, rebinding resistance, SSRF protection, and audit are part of the security boundary.

## AI authentication

An AI display name is not authentication. Supported integrations use verified OAuth or another explicitly supported credential path. Authentication remains mandatory even when AI Access policy enforcement is disabled.

## Secret handling

Configuration export, support bundles, logs, and AI copy/paste workflows must redact enrollment tickets, OAuth or bearer secrets, private keys, and equivalent protected values.

## External boundary

DataRelay Link does not weaken target OS authentication, application credentials, TLS certificates, cloud firewalls, or external NAT/DNS controls.
