# Diagnostics

## Server

```text
show status
system version
system diagnostics
system audit
system revisions
show managed-hosts
```

## Agent Host

```text
show status
show agent
show remote-services
system info
system diagnostics
```

A policy ALLOW result and a Remote Service runtime state answer different questions. Use policy test commands for authorization and Agent or Remote Service state for connectivity.

When escalation is needed, create a sanitized support bundle rather than pasting raw secrets, enrollment tickets, OAuth credentials, private keys, or full configuration databases into chat or tickets.
