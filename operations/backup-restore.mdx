# Backup & Restore

Use the product backup/restore workflow rather than copying selected live files by hand.

## Server commands

```text
system backup
system restore <FILE>
```

The v2.4 Server authoritative state includes the control-plane SQLite database plus required trust, secret, and configuration material.

A live WAL database must be backed up with a consistent SQLite backup or snapshot method. Naive copying of a live database file is not the canonical backup method.

## Restore rules

Restore is a configuration mutation. The product validates compatibility, integrity, and activation. If automatic rollback cannot fully recover a failure, diagnostics must report that truthfully rather than claiming success.

After restore, verify Managed Hosts, Objects and Groups, Remote Services visible from Server state, policies, AI Identities, revisions, and runtime health.
