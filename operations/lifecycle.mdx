# Lifecycle Semantics

DataRelay Link uses explicit lifecycle operations; do not treat unrelated actions as synonyms.

## Access Policy

Disabling preserves Mode/Rules, but the effective result differs by plane. Select the intended plane explicitly.

~~~text
set remote-access disabled
set internet-access disabled
set ai-access disabled
~~~

| Plane | Supported modes | No policy | Enforcement disabled |
| --- | --- | --- | --- |
| Remote Access | BLACKLIST / WHITELIST | ALLOW | ALLOW ALL |
| Internet Access | WHITELIST only | DENY | DENY ALL |
| AI Access | WHITELIST only | DENY | DENY ALL |

WHITELIST denies unmatched requests. BLACKLIST is supported only by Remote Access: matching enabled Rules deny, unmatched requests allow. Rules have no ordering or per-rule action. Policy reset removes Mode/Rules and returns each plane to its own initial state. AI authentication remains required independently.

~~~text
unset remote-access policy
unset internet-access policy
unset ai-access policy
~~~

## Remote Service

Disabling a Remote Service stops that connectivity while retaining the object for later re-enable. Removing a Remote Service is an explicit configuration deletion.

## Agent Host

```text
system pause
system resume
system restart
system synchronize
system autostart enable
system autostart disable
system update product
system update engine
system uninstall
```

Agent lifecycle commands belong on the Agent Host.

Normal update or restart must preserve identity and configured state; uninstall behavior is separate from Server-side object and policy cleanup.
