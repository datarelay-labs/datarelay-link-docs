# Lifecycle Semantics

DataRelay Link uses explicit lifecycle operations; do not treat unrelated actions as synonyms.

## Access Policy

```text
set <policy-family> disabled
```

preserves Mode and Rules but makes policy enforcement effectively ALLOW ALL.

```text
unset <policy-family> policy
```

removes Mode and Rules and returns to the initial No Policy / No Rules state.

## Remote Service

Disabling a Remote Service stops that connectivity while retaining the object for later re-enable. Removing a Remote Service is an explicit configuration deletion.

## Agent Host

```text
system pause
system resume
system restart
system update product
system update engine
system uninstall
```

Agent lifecycle commands belong on the Agent Host.

Normal update or restart must preserve identity and configured state; uninstall behavior is separate from Server-side object and policy cleanup.
