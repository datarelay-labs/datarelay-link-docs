# Operations Overview

Start with read-only state collection before changing configuration.

## Server

```text
show status
show version
system diagnostics
system audit
system revisions
system backup
```

## Agent Host

```text
show status
show agent
show remote-services
system info
system diagnostics
```

## Configuration changes

For a single resource, use direct CLI. For dependent multi-resource changes, use ConfigurationBundle:

```text
test configuration <FILE|->
system diff configuration <FILE|->
system apply configuration <FILE|->
```

For recovery, use revisions and the product backup/restore process instead of manually editing runtime state.
