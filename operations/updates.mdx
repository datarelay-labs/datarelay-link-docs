# Updates

The DataRelay Link product version and bundled Relay Engine version are separate.

## Server

```text
system update
```

## Agent Host

```text
system update product
system update engine
```

Stable updates use immutable qualified releases. Development or pre-release testing uses an exact immutable SHA or qualified artifact. Never silently fall back from a missing immutable ref to mutable main/latest.

A normal upgrade must preserve Managed Host/Agent identity, enrollment trust, Remote Service identity, endpoint reservations, control-plane state, policies, and release provenance.

The v2.4 Server state is stored in SQLite at `/var/lib/drlink/drlink.db`; schema changes use ordered migrations with integrity validation.
