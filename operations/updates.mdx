# Updates

The DataRelay Link product version and bundled Relay Engine version are separate.

## Server

```text
system update product
system update engine
system update check-engine
```

## Agent Host

```text
system update product
system update engine
```

Use the built-in product update command. Review the proposed version and restart impact, preserve a Server backup, and verify services after completion.

A normal upgrade must preserve Managed Host/Agent identity, enrollment trust, Remote Service identity, endpoint reservations, control-plane state, policies, and release provenance.

The Server state is stored in SQLite at `/var/lib/drlink/drlink.db`; schema changes use ordered migrations with integrity validation.
