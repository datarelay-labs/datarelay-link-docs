# drlink 사용법

기본 운영 인터페이스는 sudo drlink입니다.

## DRLink Server

```text
Managed Host / Enrollment
Network Object / Group
Service Object / Group
Permission Object / Group
AI Identity
Remote Access
Internet Access
AI Access
Server ConfigurationBundle
revision / audit / backup / restore
```

## Agent Host

```text
상태
Remote Service
Agent lifecycle
Agent ConfigurationBundle
로컬 진단
```

Remote Service 변경은 소유 Agent Host에서 수행합니다.

공통 root는 show, set, unset, test, system, menu, help, exit입니다. ?, help, contextual help, Tab을 사용해 다음 가능한 명령을 확인할 수 있습니다.
