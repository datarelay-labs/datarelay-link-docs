# drlink 사용법

기본 운영 인터페이스는 다음과 같습니다.

```bash
sudo drlink
```

## DRLink Server

```text
Managed Host / Enrollment
Network Object / Group
Service Object / Group
Permission Object / Group
AI Identity
Remote Access
Internet Access
AI Access
Server ConfigurationBundle
revision / audit / backup / restore
```

## Agent Host

```text
상태
Remote Service
Agent lifecycle
Agent ConfigurationBundle
로컬 진단
```

Remote Service 변경은 소유 Agent Host에서 수행합니다.

## 공통 명령 루트

```text
show
set
unset
test
system
menu
help
exit
```

`?`, `help`, 문맥별 도움말과 Tab 완성을 사용해 다음 가능한 명령을 확인할 수 있습니다. 역할이 다른 명령을 입력하면 소유 역할을 확인하세요.
