# DataRelay Link

**네트워크 전체를 연결하지 않고 실제로 필요한 연결만 중계합니다.**

DataRelay Link는 폐쇄망과 제한망을 위한 경량 CLI 중심 보안 연결 게이트웨이입니다.

```text
Remote Access     외부 → 승인된 내부 Remote Service
Internet Access   Managed Host/보호 소스 → 승인된 외부 목적지
AI Access         인증된 AI Identity → 승인된 대상 Permission
```

<Note>
  이 사이트는 현재 **v2.4.0 개발 대상**을 설명합니다. 정확한 HEAD 검증과 변경 불가능한 릴리스가 완료되기 전까지 v2.4.0을 안정 릴리스로 간주하지 않습니다. 현재 공개 안정 릴리스는 **v2.3.0**입니다.
</Note>

## 현재 제품 모델

```text
Managed Host / DRLink Agent

Network Object / Network Group
Service Object / Service Group
Permission Object / Permission Group

AI Identity
Remote Service

Remote Access
Internet Access
AI Access

BLACKLIST / WHITELIST
ConfigurationBundle
```

**Remote Service는 실제 연결을 만들고**, **Access Policy는 그 연결을 누가 사용할 수 있는지 결정합니다.** 정책 Rule이 Remote Service 자체를 만드는 것은 아닙니다.

## 정책 모델

초기 상태는 정책과 Rule이 없으며, 결과적으로 모든 연결이 허용됩니다.

- BLACKLIST: 활성 Rule과 일치하면 거부하고, 일치하지 않으면 허용합니다.
- WHITELIST: 활성 Rule과 일치하면 허용하고, 일치하지 않으면 거부합니다.
- Rule은 순서로 평가하지 않으며 각 Rule에 ALLOW/DENY 동작을 따로 지정하지 않습니다.
- Enforcement를 비활성화하면 Mode와 Rule은 그대로 유지되지만 실제 적용 결과는 모두 허용입니다.
- Policy Reset은 Mode와 Rule을 모두 제거합니다.

AI Access enforcement가 disabled여도 AI 인증은 필수입니다.
