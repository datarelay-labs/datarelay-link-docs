# DataRelay Link

**네트워크 전체를 연결하지 않고 실제로 필요한 연결만 중계합니다.**

DataRelay Link는 폐쇄망과 제한망을 위한 경량 CLI 중심 보안 연결 게이트웨이입니다.

## 현재 제품 모델

```text
Managed Host / DRLink Agent

Network Object / Network Group
Service Object / Service Group
Permission Object / Permission Group

AI Identity
Remote Service

Remote Access
Internet Access
AI Access

Remote Access: BLACKLIST / WHITELIST
Internet Access: WHITELIST only (default DENY)
AI Access: WHITELIST only (default DENY)
ConfigurationBundle
```

**Remote Service는 실제 연결을 만들고**, **Access Policy는 그 연결을 누가 사용할 수 있는지 결정합니다.** 정책 Rule이 Remote Service 자체를 만드는 것은 아닙니다.

## 정책 모델

정책의 초기 상태와 비활성화 의미는 연결 방향에 따라 **다릅니다.**

- **Remote Access:** No Policy/No Rules = **ALLOW**. BLACKLIST 매칭 Rule은 DENY이고 비매칭은 ALLOW입니다. WHITELIST 매칭은 ALLOW, 비매칭은 DENY입니다. Enforcement를 비활성화하면 **ALLOW ALL**입니다.
- **Internet Access:** **WHITELIST 전용, 기본 DENY**. 허용 Rule이 없거나 Enforcement가 비활성화되면 **DENY ALL**입니다. BLACKLIST는 불가능합니다.
- **AI Access:** **WHITELIST 전용, 기본 DENY**. Rule이 없거나 Enforcement가 비활성화되면 **DENY ALL**입니다. 실제 AI Identity 인증은 별도로 필요합니다.
- 세 정책 모두 Rule에 순서/개별 ALLOW·DENY action을 지정하지 않습니다. Policy Reset은 Mode와 Rule을 제거하며 각 연결 방향의 초기 정책 상태로 돌아갑니다.

## 제품 범위

DataRelay Link는 명시적으로 구성한 서비스와 승인한 목적지에 대한 연결만 중계합니다. 전체 VPN/네트워크 Overlay, 고객 클라우드 방화벽·DNS 자동 구성 또는 대규모 Fleet 관리 제품은 아닙니다.

외부 방화벽·NAT, 보안 그룹, DNS 레코드, OS 계정 및 애플리케이션 인증서는 별도 기능에 명시된 경우를 제외하면 운영자가 설정해야 합니다. [제한 사항](/ko/reference/limitations)을 참고하세요.

<Note>
  DataRelay Link는 **Source Available** 제품이며 Open Source는 아닙니다. [라이선스](/ko/reference/license)를 확인하세요.
</Note>

처음 설치해 SSH, 외부 허용 또는 MCP를 사용하려면 [목적별 신규 사용자 경로](/ko/getting-started/choose-workflow)를 따르세요.
