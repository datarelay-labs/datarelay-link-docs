# Managed Host 등록

Enrollment는 실제 Host에 DRLink Agent를 설치하고 Server에 바인딩하여 Managed Host로 만듭니다.

Server 명령:

```text
set enrollment zero-touch
set enrollment manual
set enrollment bulk
show enrollments
show enrollment <ENROLLMENT>
```

등록 후:

```text
show managed-hosts
show managed-host <HOST>
```

Managed Host identity는 label, hostname, NAT/public IP만으로 결정되지 않습니다.

Remote Service는 등록이 끝난 **Agent Host에서** 생성합니다.
