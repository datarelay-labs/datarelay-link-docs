# Zero-Touch 등록

Server에서:

```text
set enrollment zero-touch
```

## 제한

```text
요청당 최대 발급        10
동시 활성 미사용 ticket 10
기본 TTL                1시간
최대 TTL                24시간
사용 횟수               1회
```

각 ticket은 고유하며 성공적으로 사용되면 원자적으로 consume됩니다. raw ticket/install URL은 발급 시점에만 표시하고 persistent state에는 verifier/hash와 lifecycle metadata를 보존합니다.

Zero-Touch는 Agent를 등록합니다. OS 사용자, SSH 설정, cloud firewall, Access Policy Rule을 자동 생성하지 않습니다.

## DNS 없이 사용하는 최신 경로

현재 후보는 신뢰된 공개 HTTPS 호스트명 또는 Private CA fingerprint와 인증서 IP SAN을 검증한 숫자 IP 경로로 짧은 일회용 명령을 생성합니다. DNS는 필수가 아닙니다. 둘 다 준비되지 않았으면 서비스 마법사·티켓 발급 전에 오류를 냅니다. 생성된 명령을 그대로 사용하고 오래된 긴 bootstrap 예제를 수동으로 재구성하지 마세요. SSH 사용자명은 비워도 됩니다.
