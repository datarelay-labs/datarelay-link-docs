# Zero-Touch 등록

Server에서:

```text
set enrollment zero-touch
```

## 제한

```text
요청당 최대 발급        10
동시 활성 미사용 ticket 10
기본 TTL                1시간
최대 TTL                24시간
사용 횟수               1회
```

각 ticket은 고유하며 성공적으로 사용되면 원자적으로 consume됩니다. raw ticket/install URL은 발급 시점에만 표시하고 persistent state에는 verifier/hash와 lifecycle metadata를 보존합니다.

Zero-Touch는 Agent를 등록합니다. OS 사용자, SSH 설정, cloud firewall, Access Policy Rule을 자동 생성하지 않습니다.
