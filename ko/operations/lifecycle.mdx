# Lifecycle 의미

## Access Policy

```text
set <policy-family> disabled
```

Mode와 Rule을 유지하면서 enforcement를 effective ALLOW ALL로 만듭니다.

```text
unset <policy-family> policy
```

Mode와 Rule을 제거하여 초기 No Policy / No Rules 상태로 돌아갑니다.

## Remote Service

Disable은 Remote Service object를 유지하면서 connectivity를 중지합니다. 제거는 명시적인 configuration deletion입니다.

## Agent Host

```text
system pause
system resume
system restart
system update product
system update engine
system uninstall
```

Agent lifecycle 명령은 Agent Host에서 수행합니다.

일반 update/restart는 identity와 설정을 보존해야 하며 uninstall과 Server-side object/policy cleanup은 별도 작업입니다.
