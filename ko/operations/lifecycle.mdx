# Lifecycle 의미

## Access Policy

각 정책의 비활성화는 Mode/Rule을 보존하되 **결과가 다릅니다**. 명령을 실행할 정책을 명시하세요.

~~~text
set remote-access disabled
set internet-access disabled
set ai-access disabled
~~~

| 정책 | 지원 모드 | 정책 없음 | Enforcement disabled |
| --- | --- | --- | --- |
| Remote Access | BLACKLIST / WHITELIST | ALLOW | ALLOW ALL |
| Internet Access | WHITELIST 전용 | DENY | DENY ALL |
| AI Access | WHITELIST 전용 | DENY | DENY ALL |

WHITELIST는 매칭 허용 Rule이 없으면 DENY입니다. BLACKLIST는 Remote Access에서만 지원하며 매칭하면 DENY, 미일치면 ALLOW입니다. Rule 순서와 Rule별 action은 없습니다. 정책 초기화는 Mode/Rule을 삭제하고 각 정책의 초기 상태로 돌아갑니다. AI 인증은 정책 상태와 별도로 항상 필요합니다.

~~~text
unset remote-access policy
unset internet-access policy
unset ai-access policy
~~~

## Remote Service

Disable은 Remote Service 객체를 남겨 둔 채 연결만 중지합니다. 제거는 설정 자체를 삭제하는 작업입니다.

## Agent Host

```text
system pause
system resume
system restart
system synchronize
system autostart enable
system autostart disable
system update product
system update engine
system uninstall
```

Agent의 중지, 재개, 재시작, 업데이트 같은 작업은 Agent Host에서 수행합니다.

일반 업데이트와 재시작은 identity와 설정을 보존해야 합니다. uninstall과 Server 측 객체·정책 정리는 별도 작업입니다.
