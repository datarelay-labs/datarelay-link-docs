# Lifecycle 의미

## Access Policy

```text
set <policy-family> disabled
```

Mode와 Rule을 유지한 채 실제 적용 결과만 모두 허용으로 바꿉니다.

```text
unset <policy-family> policy
```

Mode와 Rule을 제거해 정책이 없는 초기 상태로 돌아갑니다.

## Remote Service

Disable은 Remote Service 객체를 남겨 둔 채 연결만 중지합니다. 제거는 설정 자체를 삭제하는 작업입니다.

## Agent Host

```text
system pause
system resume
system restart
system update product
system update engine
system uninstall
```

Agent의 중지, 재개, 재시작, 업데이트 같은 작업은 Agent Host에서 수행합니다.

일반 업데이트와 재시작은 identity와 설정을 보존해야 합니다. uninstall과 Server 측 객체·정책 정리는 별도 작업입니다.
