# 업데이트

DataRelay Link product version과 Relay Engine version은 별도입니다.

Server:

```text
system update
```

Agent Host:

```text
system update product
system update engine
```

안정 릴리스 업데이트에는 검증된 변경 불가능 릴리스를 사용합니다. 개발/프리릴리스 검증에는 정확한 SHA 또는 검증된 artifact를 사용하고, 고정된 참조가 없다는 이유로 `main`이나 `latest`로 자동 대체해서는 안 됩니다.

정상 업그레이드는 Managed Host/Agent identity, enrollment 신뢰 관계, Remote Service identity, endpoint 예약, control-plane 상태, 정책 상태와 릴리스 출처를 그대로 유지해야 합니다.

v2.4 authoritative Server state는 /var/lib/drlink/drlink.db SQLite DB이며 ordered migration과 integrity validation을 사용합니다.
