# 업데이트

설치 버전, 릴리스 채널, Relay Engine 버전 및 역할을 Server/Agent 셸의 `sudo drlink system version`으로 확인합니다. 설치 파일과 변경 내역은 [공식 배포 페이지](https://github.com/datarelay-labs/datarelay-link/releases)에서 확인합니다. Server 변경 전 [백업](/ko/operations/backup-restore)을 만들고 실제 연결을 검증하세요.


DataRelay Link product version과 Relay Engine version은 별도입니다.

Server:

```text
system update product
system update engine
system update check-engine
```

Agent Host:

```text
system update product
system update engine
```

제품 내장 업데이트 명령을 사용합니다. Windows에서는 관리자 PowerShell에서 `drlink system update product`를 실행합니다. 현장 개선 후보 버전의 설치된 Agent는 등록된 Server에서 CA 검증 HTTPS로 manifest와 SHA256SUMS를 내려받고, 릴리스 채널과 불변 소스 및 bootstrap SHA256을 검증한 뒤 재등록 없이 업그레이드합니다. `drlink system update product -Check`는 소프트웨어 적용 없이 메타데이터만 확인합니다. 정식 릴리스 전 실제 Windows 검증이 필요합니다. 표시되는 버전과 재시작 영향을 확인하고, Server 백업을 보관한 뒤 완료 후 서비스 연결을 점검하세요.

정상 업그레이드에서는 Managed Host/Agent identity, enrollment 신뢰 관계, Remote Service identity, endpoint 예약, control-plane 상태, 정책과 릴리스 출처가 유지되어야 합니다.

Server의 기준 상태는 `/var/lib/drlink/drlink.db` SQLite DB에 저장됩니다. 스키마 변경은 순서가 정해진 migration으로 적용하고 무결성을 확인합니다.
