# 업데이트

DataRelay Link product version과 Relay Engine version은 별도입니다.

Server:

```text
system update product
system update engine
system update check-engine
```

Agent Host:

```text
system update product
system update engine
```

제품 내장 업데이트 명령을 사용합니다. 표시되는 버전과 재시작 영향을 확인하고, Server 백업을 보관한 뒤 완료 후 서비스 연결을 점검하세요.

정상 업그레이드에서는 Managed Host/Agent identity, enrollment 신뢰 관계, Remote Service identity, endpoint 예약, control-plane 상태, 정책과 릴리스 출처가 유지되어야 합니다.

Server의 기준 상태는 `/var/lib/drlink/drlink.db` SQLite DB에 저장됩니다. 스키마 변경은 순서가 정해진 migration으로 적용하고 무결성을 확인합니다.
