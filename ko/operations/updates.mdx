# 업데이트

DataRelay Link product version과 Relay Engine version은 별도입니다.

Server:

```text
system update
```

Agent Host:

```text
system update product
system update engine
```

Stable update는 immutable qualified release를 사용합니다. Development/pre-release 검증은 exact immutable SHA 또는 qualified artifact를 사용합니다. immutable ref가 없다고 mutable main/latest로 자동 fallback하면 안 됩니다.

정상 upgrade는 Managed Host/Agent identity, enrollment trust, Remote Service identity, endpoint reservation, authoritative control-plane state, policy state, release provenance를 보존해야 합니다.

v2.4 authoritative Server state는 /var/lib/drlink/drlink.db SQLite DB이며 ordered migration과 integrity validation을 사용합니다.
