# 백업 & 복구

선택한 live 파일을 수동으로 복사하지 말고 제품의 backup/restore workflow를 사용합니다.

```text
system backup
system restore <FILE>
```

v2.4 Server authoritative state에는 SQLite control-plane DB와 필요한 trust, secret, configuration material이 포함됩니다.

live WAL database는 일관된 SQLite backup/snapshot 방식으로 백업해야 합니다. 실행 중인 DB 파일 하나만 복사하는 방식은 canonical backup이 아닙니다.

복구 후 Managed Host, Object/Group, Server에서 보이는 Remote Service 상태, Access Policy, AI Identity, revision, runtime health를 확인합니다.
