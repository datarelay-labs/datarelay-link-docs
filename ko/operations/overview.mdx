# 운영 개요

상태를 바꾸기 전에 read-only evidence를 먼저 확인합니다.

## Server

```text
show status
show version
system diagnostics
system audit
system revisions
system backup
```

## Agent Host

```text
show status
show agent
show remote-services
system info
system diagnostics
```

독립적인 리소스 하나는 direct CLI를 사용하고, 의존성이 있는 여러 설정은 ConfigurationBundle의 test → diff → apply 순서를 사용합니다.

복구가 필요하면 authoritative state를 직접 수정하지 말고 revision과 일관된 backup/restore workflow를 사용합니다.
