# 운영 개요

상태를 바꾸기 전에 read-only evidence를 먼저 확인합니다.

## Server

```text
show status
show version
system diagnostics
system audit
system revisions
system backup
```

## Agent Host

```text
show status
show agent
show remote-services
system info
system diagnostics
```

리소스 하나만 바꿀 때는 직접 CLI를 사용합니다. 서로 의존하는 여러 설정을 바꿀 때는 ConfigurationBundle의 `test → diff → apply` 순서를 사용합니다.

복구가 필요해도 기준 상태를 직접 수정하지 마십시오. revision을 확인하고 제품의 백업/복구 절차를 사용합니다.
