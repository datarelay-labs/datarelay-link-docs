# 문제 해결

## 1. Server / Agent health

Server:

```text
show status
system diagnostics
```

Agent Host:

```text
show status
show agent
system info
system diagnostics
```

## 2. Enrollment / management

```text
show enrollments
show managed-hosts
```

## 3. Remote Service

Agent Host에서:

```text
show remote-services
show remote-service <NAME>
```

DEGRADED는 configuration이 존재하지만 runtime health 또는 synchronization이 일시적으로 불완전할 수 있음을 의미합니다.

## 4. Policy

```text
test remote-access ...
test internet-access ...
test ai-access ...
```

Remote Service health만 보고 authorization을 추정하지 않습니다.

## 5. AI Access

AI 인증/identity → permission policy → target Agent/OS permission 순으로 확인합니다. MCP는 이 계층을 우회하지 않습니다.

필요하면 sanitized support bundle을 사용하고 ticket, OAuth/bearer secret, private key는 노출하지 않습니다.
