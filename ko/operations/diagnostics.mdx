# 진단

## Server

```text
show status
show version
system diagnostics
system audit
system revisions
show managed-hosts
```

## Agent Host

```text
show status
show agent
show remote-services
system info
system diagnostics
```

Policy의 ALLOW 결과와 Remote Service runtime 상태는 서로 다른 문제를 설명합니다. authorization은 test 명령으로, connectivity는 Agent/Remote Service 상태로 확인합니다.

지원 요청 시 ticket, bearer/OAuth secret, private key, secret-bearing database를 그대로 붙여 넣지 말고 sanitized support bundle을 사용합니다.
