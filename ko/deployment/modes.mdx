# 배포 모드

DataRelay Link Server는 Direct와 Enterprise single-443 두 배포 모드를 지원합니다.

## Direct

일반적인 public listener:

```text
TCP/443        Relay control
TCP/6099       management/enrollment HTTPS
TCP/6000-6098 Remote Service endpoint pool
```

## Enterprise single-443

Management/Enrollment HTTPS와 Relay control이 public TCP/443을 공유하고 내부 backend listener는 loopback-only로 유지됩니다.

Remote Service endpoint는 설정된 endpoint pool에서 별도로 할당됩니다.

배포 모드를 바꾸더라도 v2.4 control-plane DB, Managed Host/Agent identity, Remote Service, endpoint 예약, 정책, 신뢰 정보는 그대로 유지되어야 합니다.

설치 프로그램은 cloud security group, 외부 firewall/NAT, DNS provider record를 자동 변경하지 않습니다.

## MCP를 사용하는 경우

공개 원격 MCP는 **single443** 전용입니다. Direct의 TCP/443 Relay 제어는 HTTPS MCP가 아닙니다. [Claude / ChatGPT 연결 가이드](/ko/guides/mcp-clients)를 따르세요. 배포 모드를 바꾸면 연결이 끊길 수 있으므로 동일한 불변 소스의 installer와 검증한 백업으로 계획된 전환을 수행합니다.
