# DNS & Public Hostname

DataRelay Link는 다음 이름을 구분합니다.

| 이름 | 용도 |
| --- | --- |
| Product public identity | 설치 시 선택하는 Server control/management identity |
| Remote Service alias | Remote Service endpoint용 optional friendly hostname |
| Bootstrap hostname | Zero-Touch bootstrap entry용 optional hostname |

설치에서 domain을 product public identity로 선택했다면 생성되는 Zero-Touch 및 product-facing URL에 일관되게 사용되어야 합니다.

Remote Service alias를 바꿔도 Agent identity, policy selector, Server trust identity가 자동 변경되면 안 됩니다.

DNS provider record는 DataRelay Link가 자동 생성하지 않습니다.
