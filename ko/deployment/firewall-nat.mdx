# 방화벽 & NAT

DataRelay Link는 cloud security group, customer firewall, NAT/DNAT, UFW/firewalld, 외부 router를 자동 변경하지 않습니다.

## Direct

```text
TCP/443        Relay control
TCP/6099       management/enrollment HTTPS
TCP/6000-6098 기본 Remote Service endpoint pool
```

Fixed TCP를 사용할 경우 별도로 설정된 endpoint pool만 추가로 노출합니다.

## Enterprise single-443

```text
TCP/443        management/enrollment + Relay control
Remote Service endpoint pool(s)
```

내부 allocator/Relay Engine backend listener는 외부에 노출하지 않습니다.

Managed Host는 일반적으로 Server로 아웃바운드 연결하므로 Agent 동작만을 위해 공인 IP나 inbound NAT가 필요하지 않습니다.
