# Server 설치

## 준비 사항

- 지원되는 Linux Server와 관리자 권한
- Agent가 접속할 공인 IP 또는 DNS 이름
- [방화벽·NAT](/ko/deployment/firewall-nat)에 설명된 통신 경로
- MCP를 사용한다면 공개 DNS 이름과 HTTPS 인증서, single443 배포 모드

## 1. Server 설치 프로그램 실행

공식 Server 설치 프로그램을 다운로드하고 실행합니다.

~~~bash
curl -fsSL https://raw.githubusercontent.com/datarelay-labs/datarelay-link/main/dist/bootstrap-server.sh -o bootstrap-server.sh
sudo bash ./bootstrap-server.sh
~~~

설치 안내에 따라 외부 주소와 배포 모드를 선택합니다. Claude·ChatGPT 원격 MCP를 사용할 경우 **single443**를 선택하고 [MCP 연결 가이드](/ko/guides/mcp-clients)에서 공개 HTTPS와 OAuth를 설정합니다.

## 2. 설치 결과 확인

~~~bash
sudo drlink system version
sudo drlink show status
sudo drlink system diagnostics
~~~

역할이 **DRLink Server**이고 서비스 상태에 오류가 없는지 확인합니다. 문제가 있으면 진단 결과와 [문제 해결](/ko/operations/troubleshooting)을 확인하세요.

## 3. 필요한 연결 설정

| 목적 | 다음 단계 |
| --- | --- |
| 내부 서버 원격 접속 | [Agent 등록](/ko/guides/enrollment) → [SSH 실습](/ko/use-cases/remote-ssh) |
| 제한망의 승인된 인터넷 접속 | [Internet Access](/ko/guides/internet-access) |
| Claude·ChatGPT에서 서버 작업 | [MCP 연결](/ko/guides/mcp-clients) → [AI Access](/ko/guides/ai-access) |

Server는 등록·인벤토리·정책·AI Identity·감사·백업을 관리합니다. Remote Service는 등록된 해당 Agent Host에서 생성합니다. 외부 방화벽·DNS·SSH 계정·애플리케이션 인증서는 각 환경에서 준비하세요.
