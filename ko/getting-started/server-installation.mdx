# Server 설치

<Note>처음 설치한다면 [작업별 최초 설정 경로](/ko/getting-started/choose-workflow)에서 Server 설치, Host 등록, MCP, ACL 및 실제 허용·차단 순서를 확인하세요.</Note>

## 준비 사항

- 지원되는 Linux Server와 관리자 권한
- Agent가 접속할 공인 IP 또는 DNS 이름
- [방화벽·NAT](/ko/deployment/firewall-nat)에 설명된 통신 경로
- MCP를 사용한다면 공개 DNS 이름과 HTTPS 인증서, single443 배포 모드

## 1. Server 설치 프로그램 실행

**승인된 불변 소스 커밋 SHA** 또는 검증된 릴리스 아티팩트만 사용하세요. 변경되는 `main`·검증되지 않은 `latest`에서 설치하지 마세요. 아래 자리표시자를 실제 승인 SHA로 교체하고, 제공된 해시가 있다면 배포물도 검증하세요.

~~~bash
# 릴리스 담당자로부터 승인된 불변 40자리 Git 커밋 SHA를 확인하세요.
SOURCE_SHA="REPLACE_WITH_APPROVED_40_CHARACTER_COMMIT_SHA"
printf '%s' "$SOURCE_SHA" | grep -Eq '^[0-9a-f]{40}$' || { echo "Invalid SHA"; exit 1; }
curl -fsSL "https://raw.githubusercontent.com/datarelay-labs/datarelay-link/$SOURCE_SHA/dist/bootstrap-server.sh" -o bootstrap-server.sh
sha256sum bootstrap-server.sh  # 별도로 승인된 배포물 해시가 있다면 대조하세요.
sudo bash ./bootstrap-server.sh
~~~

설치 안내에 따라 외부 주소와 배포 모드를 선택합니다. Claude·ChatGPT 원격 MCP를 사용할 경우 **single443**를 선택하고 [MCP 연결 가이드](/ko/guides/mcp-clients)에서 공개 HTTPS와 OAuth를 설정합니다.

## 2. 설치 결과 확인

~~~bash
sudo drlink system version
sudo drlink show status
sudo drlink system diagnostics
~~~

역할이 **DRLink Server**인지, **실제 설치 소스/버전**과 서비스 상태가 정상인지 확인합니다. 설치 명령 종료만으로 정식 릴리스 검증이 완료된 것은 아닙니다. 문제가 있으면 진단 결과와 [문제 해결](/ko/operations/troubleshooting)을 확인하세요.
