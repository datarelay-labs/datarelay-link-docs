# 서버 설치

<Note>
  현재 공개 stable release는 **v2.3.0**이고, 이 사이트는 **v2.4.0 development target**을 설명합니다. stable 설치는 immutable release/tag를 사용하고 v2.4 검증은 exact qualified SHA 또는 artifact를 사용합니다.
</Note>

## Server 역할

Server는 Enrollment, Managed Host inventory, Object/Group, Access Policy, AI Identity, Audit, Backup/Restore, Server ConfigurationBundle을 관리합니다.

설치 후:

```bash
sudo drlink
```

```text
show version
show status
system diagnostics
```

Role이 DRLink Server인지 확인하고 product version, release channel, exact Source HEAD, Relay Engine version이 실제 상태와 일치하는지 확인합니다.

## Public identity

설치 시 public IP 또는 public domain을 product-facing identity로 선택할 수 있습니다. domain을 선택했다면 생성되는 Zero-Touch 및 사용자-facing URL에 일관되게 사용되어야 합니다.

Remote Service용 friendly alias와 bootstrap hostname은 별도 개념입니다.

DataRelay Link는 cloud security group, 외부 NAT/DNAT, DNS provider record, OS 사용자, SSH 설정, application TLS certificate를 자동 변경하지 않습니다.
