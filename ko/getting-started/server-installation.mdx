# 서버 설치

<Note>
  현재 공개 안정 릴리스는 **v2.3.0**이며, 이 사이트는 개발 중인 **v2.4.0**을 설명합니다. 운영 설치에는 변경되지 않는 릴리스/tag를 사용하고, v2.4 검증에는 정확한 검증 SHA 또는 artifact를 사용합니다.
</Note>

## Server 역할

Server는 Enrollment, Managed Host inventory, Object/Group, Access Policy, AI Identity, Audit, Backup/Restore, Server ConfigurationBundle을 관리합니다.

설치 후:

```bash
sudo drlink
```

```text
show version
show status
system diagnostics
```

역할이 DRLink Server인지 확인하고 제품 버전, 릴리스 채널, 정확한 소스 HEAD, Relay Engine 버전이 실제 상태와 일치하는지 확인합니다.

## Public identity

설치 시 공인 IP 또는 도메인을 제품의 외부 주소로 선택할 수 있습니다. 도메인을 선택했다면 생성되는 Zero-Touch 링크와 사용자에게 표시되는 URL에도 같은 도메인이 사용되어야 합니다.

Remote Service용 friendly alias와 bootstrap hostname은 별도 개념입니다.

DataRelay Link는 클라우드 보안 그룹, 외부 NAT/DNAT, DNS 레코드, OS 사용자, SSH 설정, 애플리케이션 TLS 인증서를 자동으로 변경하지 않습니다.
