# macOS Agent Host

지원되는 macOS 경로에서는 Apple Silicon Mac을 Agent Host로 사용합니다.

오래된 고정 bootstrap URL을 복사하지 말고 Server가 발급한 Zero-Touch 명령을 사용합니다.

## 등록

Server에서:

```text
set enrollment zero-touch
```

마법사에서 **macOS → SSH only** 또는 **Choose Remote Services**를 선택하고 호스트 이름·설명과 실제 대상 포트를 입력합니다. Zero-Touch에서 **SSH only**, **RDP only** 또는 **Choose Remote Services**로 선택한 서비스는 등록 시 Service Object·Remote Service·공인 포트 예약까지 자동 구성됩니다. 같은 서비스를 수동으로 다시 생성하지 않습니다. Agent에서 `show remote-services`로 실제 이름을 확인하세요.

발급된 명령을 대상 Mac에서 필요한 관리자 권한으로 실행합니다.

## 확인

```text
show status
show agent
system info
system diagnostics
```

## Lifecycle

```text
system pause
system resume
system restart
system synchronize
system autostart enable
system autostart disable
system update product
system update engine
system uninstall
```

DataRelay Link는 Remote Login을 활성화하거나 macOS 사용자를 생성하지 않습니다.
