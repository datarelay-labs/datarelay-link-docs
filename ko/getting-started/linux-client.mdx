# Linux Agent Host

Linux 대상 Host는 Enrollment 후 **Managed Host**가 되고 DRLink Agent를 실행합니다.

## 등록

Server에서:

```text
set enrollment zero-touch
```

출력된 1회용 명령을 대상 Linux Host에서 실행합니다.

## Agent Host 확인

```bash
sudo drlink
```

```text
show status
show agent
system info
system diagnostics
```

## Remote Service 생성

```text
set remote-service ssh-access destination this-host service ssh enabled
show remote-service ssh-access
```

다른 LAN Host를 destination으로 지정하면 현재 Agent Host가 Relay Host가 됩니다.

## Agent lifecycle

```text
system pause
system resume
system restart
system update product
system update engine
system diagnostics
system support-bundle
```

Pause/Resume/Restart/Agent update는 Agent Host 전용 lifecycle 작업입니다.
