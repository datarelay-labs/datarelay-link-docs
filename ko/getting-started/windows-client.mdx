# Windows Agent Host

Windows는 Agent Host 플랫폼입니다. DRLink Server는 Linux 기반입니다.

Server가 생성한 Enrollment 명령을 사용하고 오래된 v2.2 고정 bootstrap URL이나 legacy client CLI를 사용하지 않습니다.

## 등록

Server에서:

```text
set enrollment zero-touch
```

마법사에서 **Windows → RDP only** 또는 **Choose Remote Services**를 선택하고 호스트 이름·설명과 실제 대상 포트를 입력합니다. Zero-Touch에서 **SSH only**, **RDP only** 또는 **Choose Remote Services**로 선택한 서비스는 등록 시 Service Object·Remote Service·공인 포트 예약까지 자동 구성됩니다. 같은 서비스를 수동으로 다시 생성하지 않습니다. Agent에서 `show remote-services`로 실제 이름을 확인하세요.

발급된 Windows 설치/등록 명령을 제품 설치 안내에 따라 실행합니다.

## 확인

```text
show status
show agent
system info
system diagnostics
```

## RDP

RDP는 TCP/3389 Service Object로 표현할 수 있습니다. DataRelay Link는 Windows RDP를 활성화하거나 계정을 만들거나 Windows Firewall/NLA를 약화시키지 않습니다.

Agent lifecycle에서는 pause, resume, restart, product update, engine update, diagnostics, support bundle, uninstall을 사용합니다.
