# 빠른 시작

<Warning>
  아래 절차는 **v2.4.0 development target** 기준입니다. stable v2.4.0 release 전에는 검증 대상 exact SHA 또는 qualified artifact를 사용하십시오.
</Warning>

## 1. Server 확인

```bash
sudo drlink
```

```text
show version
show status
system diagnostics
```

Role이 DRLink Server인지 확인합니다.

## 2. SSH Service Object 준비

```text
set service-object ssh type tcp port 22
```

## 3. Zero-Touch 발급

Server에서:

```text
set enrollment zero-touch
```

출력된 1회용 설치 명령을 대상 Host에서 실행합니다.

## 4. Agent Host 확인

Agent Host에서:

```text
show status
show agent
```

## 5. Remote Service 생성

Agent Host에서:

```text
set remote-service ssh-access destination this-host service ssh enabled
show remote-service ssh-access
```

## 6. 필요하면 Remote Access 제한

Server에서:

```text
set network-object office-admin type ip value 203.0.113.10
set remote-access office-ssh mode whitelist source office-admin destination <managed-host> service ssh enabled
test remote-access source office-admin destination <managed-host> service ssh
```

## 7. 접속

```bash
ssh -p <public-port> <user>@<public-hostname>
```

DataRelay Link는 OS 계정이나 sshd 설정을 만들지 않습니다.
