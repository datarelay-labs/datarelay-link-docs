# 라이선스

## 현재 상용 상태

**DataRelay Link는 현재 Free Early Access로 제공됩니다.**

| 항목 | 현재 정책 |
| --- | --- |
| 가격 | **Early Access 기간 무료** |
| 소스 모델 | **Source Available** |
| 오픈소스 | **아님** |
| 배포 방식 | **Self-hosted / Offline-capable** |
| 지원 | **Best effort** |
| SLA | **Early Access 기간 없음** |
| 향후 General Availability 모델 | **상용 Perpetual License** |

<Note>
정식 법적 조건은 GitHub의 [DataRelay Link Early Access License 1.0](https://github.com/datarelay-labs/datarelay-link/blob/main/LICENSE)이 기준입니다. 이 페이지는 제품 및 라이선스 정책을 이해하기 위한 요약이며 LICENSE 전문을 대체하지 않습니다.
</Note>

## Early Access에서 무료로 허용되는 사용

다음 용도로 DataRelay Link를 무료로 사용할 수 있습니다.

- 개인 사용
- 교육 및 비상업적 연구
- 평가, 테스트, Lab 및 POC
- 기업·기관의 자체 내부 업무
- 허용된 목적을 위한 내부 소스코드 수정
- 고객이 직접 통제하고 운영하는 고객 소유 환경 배포
- 고객 소유 환경에 대한 유상 설치, 통합, 마이그레이션, 유지보수, 교육 또는 지원. 단, DataRelay Link 자체를 재판매하거나 관리형 서비스로 운영해서는 안 됩니다.

## 별도 상용 라이선스가 필요한 사용

DataRelay Labs의 별도 서면 상용 라이선스가 없으면 다음 행위는 허용되지 않습니다.

- DataRelay Link 재판매 또는 재라이선스
- 원본 또는 수정본을 독립 상용 제품으로 상업적 재배포
- DataRelay Link를 다른 상용 제품이나 어플라이언스에 OEM, 임베딩, 번들 또는 화이트라벨
- 상업적 제품화를 위한 리브랜딩 또는 포크
- DataRelay Link 기능을 SaaS, MSP, 호스팅, 공유, 관리형 또는 멀티테넌트 서비스로 제공
- DataRelay Link 또는 소스코드의 상당 부분을 사용해 경쟁·대체 상용 제품을 개발, 개선 또는 유지
- 저작권, 라이선스, 출처 또는 상표 고지 제거·은폐
- DataRelay Link를 OSI 승인 오픈소스 소프트웨어로 표현

## 향후 Commercial General Availability

DataRelay Labs는 Early Access와 제품 안정화 검증이 완료된 뒤 DataRelay Link를 Commercial General Availability로 전환할 계획입니다.

계획된 상용 모델은 다음과 같습니다.

- **Perpetual Software License**
- Self-hosted 및 Offline 환경 지원
- 라이선스된 버전을 계속 사용하는 데 구독 필수 아님
- 유지보수 및 기술지원은 선택 사항 또는 별도 라이선스
- 상용 SKU와 entitlement 범위는 General Availability 발표 시 확정

향후 General Availability 릴리스에는 상용 라이선스가 필요할 수 있으며 Early Access와 다른 라이선스 조건이 적용될 수 있습니다.

Early Access License는 해당 라이선스와 함께 배포된 복사본과 버전에 적용됩니다. 향후 릴리스에 대한 접근, 업그레이드, 유지보수, 지원 또는 라이선스 권리를 자동으로 부여하지 않습니다.

## Early Access 지원 정책

Early Access는 실제 환경 사용, 검증, 테스트, 피드백 및 제품 안정화를 목적으로 합니다.

DataRelay Labs가 별도로 서면 합의하지 않는 한:

- SLA는 제공하지 않습니다.
- 기술지원은 Best Effort입니다.
- Early Access 릴리스 사이에서 기능, 인터페이스, 패키징, 호환성 및 문서가 변경될 수 있습니다.
- 각 환경에 대한 적합성 검증은 운영자의 책임입니다.

## 왜 Source Available인가요?

소스코드는 사용자가 직접 검토하고 평가·테스트하며 허용된 내부 수정에 활용할 수 있도록 공개됩니다.

다만 재판매, 상업적 제품화, 경쟁 제품, SaaS/MSP/호스팅 사용에는 제한이 있으므로 DataRelay Link는 **Open Source가 아니라 Source Available**입니다.

| 사용 시나리오 | Early Access |
| --- | --- |
| 개인 서버에서 DataRelay Link 사용 | 허용 |
| 회사 내부 운영에 사용 | 허용 |
| 허용된 내부 환경에 맞게 소스 수정 | 허용 |
| Lab 또는 POC에서 평가 | 허용 |
| 고객 소유 환경에 설치하고 고객이 직접 운영 | 허용 |
| 해당 고객 환경의 설치, 마이그레이션, 교육 또는 지원 비용 청구 | 허용 |
| 포크 후 이름을 바꿔 다른 제품으로 판매 | 허용 안 됨 |
| 상용 보안·연결 제품에 DataRelay Link를 임베딩 | 허용 안 됨 |
| DataRelay Link 기능을 SaaS/MSP/관리형 서비스로 판매 | 허용 안 됨 |
| 소스를 이용해 경쟁 제품을 개발 또는 개선 | 허용 안 됨 |
