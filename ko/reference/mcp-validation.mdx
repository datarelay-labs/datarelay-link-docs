# Claude·ChatGPT MCP 호환성

DataRelay Link는 Claude와 ChatGPT에서 원격 MCP로 연결해 사용할 수 있습니다. 두 클라이언트에서 실제 OAuth 연결, 도구 검색, 명령 실행과 파일 생성·읽기·삭제를 확인했습니다.

## 연결과 기본 기능

| 항목 | Claude | ChatGPT |
| --- | --- | --- |
| 원격 HTTPS MCP 연결 | 확인 | 확인 |
| OAuth 인증·운영자 승인 | 확인 | 확인 |
| 도구 검색 | 확인 | 확인 |
| Server 정보·명령 실행 | 확인 | 확인 |
| 파일 생성·읽기·삭제 | 확인 | 확인 |

클라이언트의 계정·워크스페이스 정책과 DataRelay Link의 AI Access에 따라 실제 사용할 수 있는 작업이 결정됩니다. 인증에 성공해도 허용하지 않은 대상·작업·파일 경로에는 접근할 수 없습니다.

## 사용할 수 있는 작업

- 등록된 Managed Host의 시스템·프로세스 정보 조회
- 지정한 파일 경로의 읽기·쓰기·업로드·다운로드
- Server 자체의 명령 실행, Git 작업, 비동기 작업의 출력·입력·중지
- AI Access 감사 기록을 통한 실제 허용·거부 확인

[20개 도구의 권한과 인자](/ko/reference/mcp-tools)를 확인하세요. OS 계정의 권한과 외부 서비스의 인증은 별도로 적용됩니다. GitHub 작업에는 해당 저장소의 Git 인증도 필요합니다.

## 연결 후 확인하기

Claude 또는 ChatGPT에 다음을 요청합니다.

~~~text
DataRelay Link만 사용해 get_server로 연결된 Server를 확인해줘.
내가 접근할 수 있는 Managed Host를 list_hosts로 보여줘.
아직 명령 실행이나 파일 변경은 하지 마.
~~~

Server 관리 권한과 Managed Host 접근 권한은 별도입니다. 호스트 목록이 비어 있어도 Server 자체 접근이 가능할 수 있습니다. 이어서 [읽기 전용 접근](/ko/use-cases/ai-readonly) 또는 [파일·Git·작업 실습](/ko/use-cases/ai-server-control)을 따르세요.

## 문제가 생겼을 때

| 증상 | 확인할 항목 |
| --- | --- |
| TLS 오류 | 공개 MCP 호스트명, 인증서, 외부 HTTPS 접근 |
| OAuth 요청 없음/만료 | 승인할 Server와 브라우저의 현재 요청 |
| AI Access DENY | 실제 identity, 대상, permission, paths |
| OS permission 오류 | 제품의 실행 계정과 대상 파일·명령의 권한 |
| 일부 도구가 안 보임 | 클라이언트에 저장된 도구 목록과 계정 정책 |

[클라이언트별 연결 절차](/ko/guides/mcp-clients)에서 복구 방법을 확인하세요.
