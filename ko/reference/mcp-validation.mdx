## 빌드와 공개 릴리스는 별도

- 공개 stable은 GitHub Release **v2.3.0**입니다.
- 본문 CLI는 main **0feab808aaaa51102d8a7988d09433da916bfcec**의 참조와 설치본 help를 대조했습니다.
- Native MCP 확장 후보는 **e4f66183fae6bd13a1611e809182838612b4fdc1**, [PR #224](https://github.com/datarelay-labs/datarelay-link/pull/224)는 확인 시 Draft/미병합입니다. 해당 MCP 모듈만 배포되었으므로 일반 system version의 Source HEAD와 다를 수 있습니다. 설치된 MCP 모듈 해시·배포 영수증을 함께 확인하세요.
- 개발 서버 테스트는 모든 환경/클라이언트/기능의 정식 릴리스 인증을 의미하지 않습니다. Claude 비동기 stdin/stop 전체와 Native MCP의 원격 GitHub push는 별도로 입증되지 않았습니다. 기존 전체 CLI E2E 결과를 MCP 결과로 대체하지 않습니다.

## 문서 예제 실호출 기록

입력/출력 예제 작업 **sj_10488471ec2c3e092d2438b4998477b8**: READY 이후 data=DRLink documentation sample와 줄바꿈, eof=true; accepted_bytes=28, input_closed=true; stdout_cursor=6부터 ECHO:DRLink documentation sample, exit_status=0.

중지 예제 작업 **sj_0ee3af01f5334c01725876d08e503e48**: server_exec의 sleep 30을 만든 뒤 본인 작업에 server_job_stop 호출; state=completed, exit_status=-9. 이는 의도한 중지이며 정상 명령 완료 exit 0과 구분합니다. 두 작업은 종료되었고 기존 제품 작업은 건드리지 않았습니다. job ID는 역사적 증거이며 다시 호출할 대상으로 사용하지 마세요.
