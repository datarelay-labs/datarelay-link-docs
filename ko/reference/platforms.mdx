# 지원 플랫폼 & 제한

| 역할 | 플랫폼 경계 |
| --- | --- |
| DRLink Server | Linux 기반 |
| Agent Host | Linux 및 qualified macOS/Windows path |

정확한 지원 범위는 릴리스 검증 결과로 결정합니다. 코드가 존재한다는 이유만으로 안정 지원 대상으로 간주하지 않습니다.

이 사이트는 **v2.4.0 개발 대상**을 설명하며 최신 공개 안정 릴리스는 **v2.3.0**입니다.

제품은 몇 대에서 몇십 대 정도의 Managed Host를 운영하는 환경을 목표로 합니다. 대규모 endpoint fleet 관리 제품은 아닙니다.

Managed Host는 일반적으로 Server로 아웃바운드 연결하므로 Agent 동작을 위해 각 호스트에 공인 IP나 inbound NAT를 둘 필요가 없습니다.
