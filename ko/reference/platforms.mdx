# 지원 플랫폼 & 제한

| 역할 | 플랫폼 경계 |
| --- | --- |
| DRLink Server | Linux 기반 |
| Agent Host | Linux 및 qualified macOS/Windows path |

정확한 지원 matrix는 release qualification evidence에 따라 결정됩니다. 코드가 존재한다는 이유만으로 stable 지원으로 간주하지 않습니다.

이 사이트는 **v2.4.0 development target**을 설명하며 최신 공개 stable release는 **v2.3.0**입니다.

제품 목표 규모는 몇 대에서 몇십 대 정도의 Managed Host입니다. 대규모 endpoint fleet orchestration 제품이 아닙니다.

Managed Host는 일반적으로 Server로 아웃바운드 연결하며 Agent 동작을 위해 각 Host에 공인 IP나 inbound NAT가 필요하지 않습니다.
