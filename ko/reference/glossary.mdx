# 용어집

| 용어 | 의미 |
| --- | --- |
| DRLink Server | 중앙 control/policy authority와 public relay entry |
| Managed Host | DRLink Agent로 등록·관리되는 실제 Host |
| DRLink Agent | Managed Host에서 실행되는 runtime |
| Network Object / Group | IP, CIDR, FQDN, Managed Host selector와 Group |
| Service Object / Group | TCP, UDP, Fixed TCP 서비스 정의와 Group |
| Permission Object / Group | AI 작업 권한과 Group |
| AI Identity | AI Access에서 인증된 identity |
| Remote Service | destination과 Service Object를 연결하는 Agent-owned connectivity |
| Relay Host | 다른 LAN destination으로 중계하는 Agent Host |
| Remote Access | Remote Service inbound 사용 권한 |
| Internet Access | 통제된 outbound destination 권한 |
| AI Access | AI Identity에서 target Permission으로의 권한 |
| BLACKLIST | Rule 일치 DENY, 미일치 ALLOW |
| WHITELIST | Rule 일치 ALLOW, 미일치 DENY |
| ConfigurationBundle | 여러 리소스를 validate/diff/apply하는 설정 문서 |
| DEGRADED | 설정은 존재하지만 runtime/sync health가 불완전한 상태 |
