# 릴리스 상태

## 현재 공개 stable

GitHub의 최신 공개 안정 릴리스는 **v2.3.0**입니다.

운영 설치에는 변경되지 않는 릴리스/tag와 해당 버전으로 검증된 artifact를 사용해야 합니다.

## 현재 개발 대상

이 문서는 **v2.4.0 개발 대상**을 기준으로 업데이트하고 있습니다.

v2.4의 Managed Host / Object / Remote Service / Remote Access / Internet Access / AI Access / ConfigurationBundle 모델을 설명합니다.

<Warning>
  v2.4 소스, VERSION 값, 브랜치 이름이나 문서가 존재한다는 사실만으로 안정 릴리스가 되는 것은 아닙니다. 정확한 HEAD 검증과 변경 불가능한 릴리스/tag가 필요합니다.
</Warning>

DataRelay Link 제품 버전과 Relay Engine 버전은 별도로 관리합니다. 현재 v2.4 개발 대상에서 고정한 Relay Engine은 릴리스 메타데이터가 바뀌지 않는 한 FRP 0.71.0입니다.
