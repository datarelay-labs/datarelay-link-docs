# 릴리스 상태

## 현재 공개 stable

GitHub의 최신 공개 stable release는 **v2.3.0**입니다.

Stable 운영 설치는 immutable release/tag와 해당 qualified artifact를 사용해야 합니다.

## 현재 개발 대상

이 문서는 **v2.4.0 development target** 기준으로 업데이트되고 있습니다.

v2.4의 Managed Host / Object / Remote Service / Remote Access / Internet Access / AI Access / ConfigurationBundle 모델을 설명합니다.

<Warning>
  v2.4 source tree, VERSION 값, branch 이름, 문서가 존재한다는 사실만으로 v2.4가 stable이 되는 것은 아닙니다. exact-HEAD qualification과 immutable release/tag가 필요합니다.
</Warning>

DataRelay Link product version과 Relay Engine version은 별도입니다. 현재 v2.4 development target의 pinned Relay Engine은 release metadata가 바뀌지 않는 한 FRP 0.71.0입니다.
