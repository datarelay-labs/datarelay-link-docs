# 제품 버전과 업데이트

## 설치된 버전 확인

Server 또는 Agent Host의 일반 셸에서 실행합니다.

~~~bash
sudo drlink system version
~~~

제품 버전, 릴리스 채널, Relay Engine 버전과 역할이 표시됩니다. Server와 Agent에서 문제가 생기면 이 정보를 함께 확인하세요.

## 제품과 Relay Engine

DataRelay Link 제품과 포함된 Relay Engine은 버전을 별도로 관리합니다. 제품 업데이트는 관리 기능과 보안·호환성 개선을 적용하고, 엔진 업데이트는 연결 엔진을 갱신합니다.

~~~text
system update product
system update engine
~~~

실행 위치와 업데이트 영향을 먼저 확인하세요. Server 변경 전에는 [백업](/ko/operations/backup-restore)을 만들고, 적용 후 상태와 실제 서비스 연결을 점검합니다. 자세한 절차는 [업데이트](/ko/operations/updates)를 참고하세요.

## 이 매뉴얼의 범위

이 사이트는 설치된 제품의 Managed Host, Remote Service, Remote Access, Internet Access, AI Access와 ConfigurationBundle 사용법을 설명합니다. 명령이 보이지 않는 오래된 설치본은 제품 업데이트 후 다시 확인하세요. 설치 파일과 변경 내역은 [공식 배포 페이지](https://github.com/datarelay-labs/datarelay-link/releases)에서 확인할 수 있습니다.

Server에서 엔진 업데이트 가능 여부만 조회하려면 `system update check-engine`을 사용합니다.
