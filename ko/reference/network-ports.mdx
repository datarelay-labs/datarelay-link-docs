# 네트워크 포트

## Direct

| 용도 | 일반적인 listener |
| --- | --- |
| Relay control | TCP/443 |
| Management / Enrollment HTTPS | TCP/6099 |
| 기본 Remote Service endpoint pool | TCP/6000-6098 |

## Enterprise single-443

| 용도 | listener |
| --- | --- |
| Public management/enrollment + Relay control | TCP/443 |
| Remote Service endpoint pool | 설정된 public range |
| Internal allocator / relay backend | loopback only |

Fixed TCP는 별도 설정된 endpoint pool을 사용합니다. Service Object의 destination port와 public endpoint port는 동일한 개념이 아닙니다.

Installer는 cloud firewall, 외부 NAT, DNS policy를 자동 변경하지 않습니다.
