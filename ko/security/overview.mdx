# 보안 개요

## Enrollment

Zero-Touch ticket은 single-use이며 TTL이 있습니다. raw ticket은 정상적인 재조회 가능한 persistent secret으로 저장하지 않습니다.

## Agent identity

Managed Host identity는 hostname, label, 관찰된 NAT/public IP만으로 결정되지 않고 enrolled Agent/machine identity를 사용합니다.

## Access Policy

Remote Access, Internet Access, AI Access는 BLACKLIST 또는 WHITELIST Mode와 ENABLED/DISABLED Enforcement를 사용합니다.

Rule은 unordered이고 Rule별 action이 없습니다.

Enforcement disabled는 Mode/Rule을 유지하면서 effective ALLOW ALL이며 Reset은 Mode/Rule을 제거합니다.

## Internet Access

Open proxy가 되지 않도록 destination/protocol/port 검증, 안전한 DNS 처리, rebinding 저항, SSRF/private/local/metadata destination 차단이 필요합니다.

## AI 인증

AI display name은 인증이 아닙니다. 지원되는 OAuth 또는 명시적 credential path로 AI Identity를 검증해야 합니다. AI Access enforcement가 disabled여도 인증은 필수입니다.

## Secret

Configuration export, support bundle, log, AI copy/paste에는 enrollment ticket, OAuth/bearer secret, private key 등 보호값이 redaction되어야 합니다.
